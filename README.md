# wanna

やりたいことを「縦軸 × clau度」の4区分に置いて、自分の好きな順に並べておくリスト。
次にやることは「学校 / その他」の2段に分け、日時を入れたものは日時の位置に入る。
ターミナルで使う TUI (`wanna`) が本体で、自宅サーバーの `wannad` を通してブラウザ版と同期する。

## タブ

| タブ | 中身 |
|---|---|
| **Want** | やりたいこと。縦軸はエネルギー（取りかかるのに要る気力）。日時は持たない |
| **Must** | 次にやること。上が「学校」、下が「その他」の2段で、上から順にやる。日時を入れる・段を移すと段の中の日時の位置に入り、あとは手で並べ替えられる |
| **Done** | やったもの。Want・Must を混ぜて、やった日の新しい順 |
| **Archive** | やってはいないが、リストに置くほどでもなくなったもの |
| **Memo** | 区分を持たないメモ。日付と名前だけ並び、本文は vim で書く |

Want の横軸の **clau度** は Claude Code に任せられる度合い。右が高い。Must は clau度で分けない。

## インストール

Rust (cargo) が要る。

```sh
make install-tui          # ~/.cargo/bin/wanna に入る。更新も同じコマンド
wanna                     # 起動
```

### サーバーと同期する

`~/.config/wanna/config.toml` に wannad の場所と token を書く（例: `tui.config.example.toml`）。

```toml
server = "http://100.x.x.x:8787"
token = "change-me"
```

環境変数 `WANNA_SERVER` / `WANNA_TOKEN` があればそちらが優先。
設定が無ければローカルのみで動き、変更は手元に溜めておいて、設定したときにまとめて送る。
オフラインでも使え、つながったら送り直す。

## キー操作

vim に合わせてある。`?` でいつでも一覧を出せる。

### どの画面でも

| キー | 動作 |
|---|---|
| `gt` / `gT` | 次 / 前のタブ。`3gt` で3番目のタブ。`]` / `[`、`Tab` / `Shift+Tab` でも |
| `j` / `k` / 矢印 | 下 / 上。`3j` のように数字を前に付けるとその回数 |
| `gg` / `G` | 先頭 / 末尾。`5G` で5番目（行の左の番号） |
| `Ctrl+d` / `Ctrl+u` | 半ページ下 / 上 |
| `/` → `n` / `N` | 名前で検索 → 次 / 前の一致。大文字を含まなければ大文字小文字を区別しない |
| `u` / `Ctrl+r` | 取り消す / やり直す（起動中のみ） |
| `v` | ビジュアルモード（後述） |
| `dd` | 削除。`3dd` で3件。確認は出さないので、間違えたら `u` |
| `m` | メモをエディタで開く |
| `r` | 今すぐ同期 |
| `:` | コマンド。`:q` 終了、`:w` 同期、`:5` 5番目へ、`:noh` 検索の色を消す |
| `q` / `Ctrl+C` | 終了（`Esc` では終わらない） |

### Want / Must

| キー | 動作 |
|---|---|
| `h` / `l` | 左 / 右の区分へ。Must は学校 / その他の段へ。`j` `k` は区分の端で上下の区分（段）へ抜ける |
| `o` / `O` | カーソルの下 / 上に追加 |
| `c` / `Enter` | 編集（名前・縦軸・clau度・日時。Must は名前・学校 / その他・日時） |
| `s` | 日時を編集（Must のみ） |
| `t` | やった（Done へ） |
| `a` | しまう（Archive へ） |
| `p` / `P` | `dd` で消したものをカーソルの下 / 上に貼る。別の区分やリストに貼れば移せる |
| `J` / `K` | 下 / 上へ動かす。`3J` で3つ。Want は区分の端で上下の区分へ移る。Must は段の中だけで動く |
| `H` / `L` | 左 / 右の区分へ動かす。Must は学校 / その他の段へ移し、行き先では日時の位置に入る |
| `X` | もう一方のリストへ移す。Must へは「その他」に、Want へは持っている区分の末尾に入る |

### Done / Archive

| キー | 動作 |
|---|---|
| `p` | 元のリストに戻す |
| `t` | やった（Archive のみ） |
| `Esc` | 直前のリストへ戻る |

### Memo

| キー | 動作 |
|---|---|
| `o` | 名前を入れて作り、そのまま本文をエディタで開く |
| `Enter` / `m` | 本文をエディタで開く |
| `c` | 名前を変える |
| `p` | `dd` で消したメモを戻す |

### ビジュアルモード

`v` で始め、`j` `k` `gg` `G` で範囲を広げてからまとめて操作する。`o` で範囲の反対の端へ、`Esc` / `v` でやめる。

| キー | 動作 |
|---|---|
| `d` | 削除（`p` で貼れる） |
| `t` / `a` | やった / しまう |
| `J` / `K` | 範囲ごと下 / 上へ（Want / Must） |
| `H` / `L` / `X` | 左右の区分（Must は学校 / その他） / もう一方のリストへ |
| `p` | 元のリストに戻す（Done / Archive） |

### 追加の入力（`o` / `O`）

vim の `o` と同じく、`Enter` でも `Esc` でも `jj` でも確定する（`~/.vimrc` の `inoremap jj <Esc>`）。空なら何も作らない。
やめるときは `Ctrl+C`。入力中は `Ctrl+W`（1語消す）・`Ctrl+U`（行頭まで消す）・`Ctrl+A` / `Ctrl+E` が使える。

### 編集ポップアップ（`c` / `Enter` / `s`）

名前と日時の欄は vim と同じく挿入モードとノーマルモードを持つ。開いた直後は挿入モード。

| モード | キー | 動作 |
|---|---|---|
| 挿入 | `Esc` / `jj` | ノーマルモードへ |
| ノーマル | `j` / `k` | 欄の移動（移った先はノーマルモード） |
| ノーマル | `h` / `l` / `Space` | 左 / 右 / 反転（高低・学校 / その他 の欄） |
| ノーマル | `i` `a` `I` `A` | 挿入モードへ |
| ノーマル | `h` `l` `w` `b` `e` `0` `$` | カーソル移動（名前・日時の欄） |
| ノーマル | `x` `D` `dd` `dw` `cc` `cw` `C` `S` `s` | 消す / 書き換える |
| ノーマル | `Esc` / `q` / `:q` / `ZQ` | やめる（書いた内容は捨てる） |
| どちらでも | `Enter` / `Ctrl+S`（ノーマルでは `:w` / `ZZ` も） | 保存 |
| どちらでも | `↑` `↓` | 欄の移動 |
| どちらでも | `Tab` | メモをエディタで編集 |

日時は `2026-09-25` / `09-25 14:00` / `明日 18:00` / `金` のように書ける。空にすると消える。

### エディタ

メモは `$VISUAL` → `$EDITOR` → `vim` の順に見つかったもので開く。
Want / Must の空のメモには見出し（`Why` / `Done when` / `Next steps` / `Log` / `Open questions`）を入れて開き、
見出しのまま閉じたら空に戻す。Memo には何も入れない。

## コマンドライン

引数を付けると TUI を開かずに1件を読み書きする（Claude Code の `/wanna` スキルが使う）。
常にサーバーへ直接読み書きする。

```
wanna ls [--want|--must|--memo] [--done|--archived] [--json]
wanna show [ID] [--json]
wanna new <タイトル> [--want] [--lo] [--no-clau] [--due <日時>] [--link]
wanna log [-c] <ID> <テキスト...>
wanna note <ID> <見出し> [テキスト...|-]
wanna title <ID> <タイトル...>
wanna due <ID> <日時...|->
wanna done <ID>
wanna archive <ID>
wanna link [ID] / wanna unlink
```

ID は全体か末尾の一部（`ls` の左端）。`@` はこのディレクトリに紐付けた1件
（リポジトリ直下の `.claude/wanna.local.toml`）。

## 構成

| ディレクトリ | 中身 |
|---|---|
| `tui/` | TUI とコマンドライン (`wanna`)。手元のキャッシュは `~/.config/wanna/cache.db` |
| `server/` | バックエンド (`wannad`)。SQLite に保存し、SSE で変更を知らせる。ブラウザ版を埋め込んで配る |
| `web/` | ブラウザ版 (TypeScript + Vite, PWA)。Memo は CodeMirror 6 の vim モードで書け、キー操作と見た目は `~/.vimrc`（habamax + vim-airline）に寄せている |
| `core/` | 共有部分（モデル・日時・並び順・API クライアント） |
| `migrate/` | Google Tasks からの一度きりの移行 |
| `deploy/` | systemd のユニット、デプロイとバックアップのスクリプト |

```sh
make test                 # Rust と web のテスト
make deploy               # wannad を入れ替える（DB をバックアップし、応答が無ければ元に戻す）
make deploy DEPLOY_HOST=… # 入れ替え先を変える（既定は dynabook）
```

サーバーを初めて置くときは、サーバー側で `make install-server` を実行し、
`~/wanna/config.toml`（例: `config.example.toml`）に bind・token・db を書いて
`deploy/wannad.service` を有効にする。到達性は Tailscale を前提にしていて、外には開けない。
